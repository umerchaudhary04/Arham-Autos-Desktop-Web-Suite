# Arham Autos - Design System (POS)

## Core Styles
- **Typography:** Inter (native windows fallback to Segoe UI).
- **Colors:** 
  - Primary: `Colors.blueGrey[900]`
  - Background: `Colors.white`
  - Accent/Focus: `Colors.blueAccent`
  - Warning/Error: `Colors.redAccent` (for limit reached)
- **Layout:** Minimalistic tables, thin native windows scrollbars, keyboard-first navigation focus.
- **Components:** High-speed textfields with auto-focus.

## UX Guidelines
- No emojis as UI icons. Use Material/Lucide.
- Visible focus states.
- Contrast compliant text.
