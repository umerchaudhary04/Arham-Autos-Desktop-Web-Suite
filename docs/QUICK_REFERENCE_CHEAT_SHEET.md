# Arham Autos POS - Quick Reference Cheat Sheet

## Hotkeys (POS Counter)
- **F1**: New Invoice
- **F2**: Focus Barcode Search
- **F3**: Focus Name Search
- **F4**: Change Price Mode (Retail/Wholesale)
- **F5**: Switch Customer
- **F8**: Add Discount
- **F9**: Process Payment & Print
- **ESC**: Clear Current Bill

## Quick Troubleshooting
- **Printer Not Responding**: Check cable, ensure paper is loaded, and verify Windows Printer Settings.
- **Stock Not Deducting**: Ensure invoice is fully finalized (not in draft state).
- **Cannot Process Return**: Operator must create a draft; Manager must approve it.
- **Credit Limit Error**: Ask Manager for the 4-digit override PIN.
